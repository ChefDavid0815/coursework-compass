# Coursework Compass

Coursework Compass is a calm, premium coursework planning product for students. Phase 1 establishes the product’s new design foundation and landing experience.

## Stack

- Next.js 16 App Router
- React 19 and strict TypeScript
- Tailwind CSS 4 foundation with a compact CSS-token design system
- `next-themes` for system-aware light and dark modes
- Lucide for restrained, consistent iconography

## Run locally

```bash
pnpm install
pnpm dev
```

Open [http://localhost:3000](http://localhost:3000).

## Quality checks

```bash
pnpm typecheck
pnpm lint
pnpm build
```

Durable visual and interaction decisions live in [`docs/design-system.md`](docs/design-system.md).
